# Inventário de telas — Valora Insight™

> Atualizado em 04/09/2026 a partir das Razor Views do `Valora.Web`. Todas as telas foram classificadas; componentes parciais compartilhados são inventariados em seção própria.

## Critérios

- **P0:** jornada crítica, autenticação, coleta ou entregável. **P1:** operação frequente/administração. **P2:** módulo especializado.
- O shell interno injeta manual curto, botão **Como usar**, próximo passo, cuidado, permissões e mensagens em todas as páginas autenticadas.
- “A validar” significa validação E2E dependente de API/PostgreSQL; não indica botão deliberadamente sem ação.

## Achados e decisões transversais

1. O manual contextual é renderizado pelo `PageExperienceViewComponent` no layout interno; páginas novas recebem fallback seguro e não ficam sem classificação.
2. A Central de Ajuda cobre implantação, módulos, formulários, diagnósticos, respostas, resultados, relatórios, certificados, ações e administração.
3. O onboarding cobre as 12 etapas solicitadas, mostra progresso, persiste marcações e confirma conclusão/reabertura.
4. Tabelas mantêm rolagem apenas no próprio container; o `body` bloqueia overflow horizontal global; cards, ações e formulários empilham no mobile.
5. Ações e formulários marcados “a validar” precisam de API e PostgreSQL ativos para homologação completa em desktop e mobile.

## Matriz de validação visual

| Resolução | Critério | Estado |
|---|---|---|
| 1366×768 | Shell, sidebar recolhível, topbar e conteúdo sem overflow global | Preparado por CSS; E2E pendente de runtime .NET |
| 1440×900 | Cards e tabelas no container | Preparado por CSS; E2E pendente de runtime .NET |
| 1920×1080 | Limite de leitura e distribuição dos cards | Preparado por CSS; E2E pendente de runtime .NET |
| Tablet | Grid adaptável e navegação offcanvas | Preparado por breakpoints |
| Celular | Uma coluna, ações em largura total e modal dentro da viewport | Preparado em ≤600px |
