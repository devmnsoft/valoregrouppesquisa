# Pendências reais de operação

- Homologar os fluxos contra uma instância PostgreSQL com o script oficial aplicado.
- Configurar uma conta `platform_admin` e carteiras de consultores para o smoke autenticado.
- Validar notificações externas e política operacional de SLA com a equipe responsável.
- Executar testes automatizados somente na fase final, conforme decisão desta execução.
