# LEGACY_PUBLIC_SURVEY_SUBMIT_FLOW

Sprint 73 define que links públicos demonstrativos não são processados em produção. A pesquisa gratuita oficial deve ser localizada por status ativo/publicado/aberto, visibilidade pública e critério gratuito, usando somente token público na URL. Conforme a política vigente, o submit público gratuito usa exclusivamente a Cloud Function `submitSurveyResponse`: não realiza fallback de escrita direta no Firestore nem para API externa. Resultado, e-mail e certificado usam IDs reais e logs/diagnósticos sanitizados. Hosting deve publicar somente após build em dist e validação sem artefatos proibidos.
