# Devolutiva pública Valora Insight™

A abertura pública identifica o diagnóstico, duração, gratuidade, formato e escala Likert completa. A devolutiva mostra o resultado fornecido pela API, dimensões, transparência metodológica, mensagem institucional e contatos oficiais.

O benchmark não é inferido: sem base autorizada a interface informa “Comparativo setorial ainda não informado para este diagnóstico.” O token de resultado permanece tratado pelo fluxo público existente e IDs não são apresentados como conteúdo da devolutiva.
