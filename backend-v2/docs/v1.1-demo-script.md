# Roteiro de demonstração v1.1

1. Fazer login com usuário administrador.
2. Abrir Form Builder.
3. Criar formulário “Checklist de Visita Comercial”.
4. Adicionar seções e campos obrigatórios.
5. Publicar formulário.
6. Responder formulário em uma tarefa.
7. Adicionar anexo/foto como evidência.
8. Criar automação para tarefa atrasada.
9. Simular tarefa atrasada.
10. Ver notificação na central.
11. Criar relatório “Pedidos por período”.
12. Exportar CSV.
13. Ver auditoria.
14. Ver Worker processando automações em logs.
