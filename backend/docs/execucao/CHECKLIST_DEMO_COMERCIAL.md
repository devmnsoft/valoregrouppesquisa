# Checklist da demonstração comercial

- [ ] Confirmar badge de ambiente e organização sintética.
- [ ] Login, Dashboard e bloco **Prontidão para Homologação**.
- [ ] Organização, estrutura, plano e usuário administrativo.
- [ ] Criar/abrir diagnóstico, publicar e copiar link público real.
- [ ] Consentimento LGPD, resposta pública e conclusão.
- [ ] Participação e Centro de Processamento.
- [ ] Evidências, Metrics, Índices, Inferências e Insights.
- [ ] Action, Evolution, Journey, Heatmap e Radar.
- [ ] Preview real de Executive Report e certificado; se indisponível, apresentar a mensagem honesta da tela.
- [ ] Governança, Auditoria, Notificações, Planos/Uso e Saúde do Sistema.
- [ ] Command Palette e navegação sem 404.

Não apresente registros seed como resultados reais. Recarregue a prontidão após cada etapa para confirmar persistência.
