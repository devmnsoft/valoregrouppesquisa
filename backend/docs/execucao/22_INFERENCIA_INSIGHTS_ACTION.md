# Inferência, Insights e Action

O motor continua exigindo três evidências convergentes para produzir inferência elegível. Evidence sem score ou com mapeamento pendente é excluída pela coluna canônica de elegibilidade.

A transformação de Insight em Action agora valida no backend que o Insight pertence à organização e contém IDs de evidências. A justificativa é derivada da proveniência persistida; IDs de inferência e conceito são herdados quando presentes. Um ID arbitrário ou Insight sem evidência é rejeitado.
