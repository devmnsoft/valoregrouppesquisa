# Guia do Layout SaaS Valora

## Layout público
O layout público carrega o design system, `valora-public.css`, topbar pública, footer institucional, modais, toasts, bot e ações flutuantes.

## Layout administrativo
O layout admin carrega o design system, `app.css`, `valora-admin.css`, `responsive.css` e parciais de sidebar/topbar. O admin deve manter fundo `#f4fafb`, cards brancos e hierarquia executiva.

## Menu por perfil
A sidebar é agrupada em Visão Geral, Gestão, Diagnósticos, Inteligência e Operação. Participante e convidado externo não devem receber painel administrativo.

## Dashboard
Não usar dados fake. Quando a API não retornar base suficiente, exibir estado vazio real.
