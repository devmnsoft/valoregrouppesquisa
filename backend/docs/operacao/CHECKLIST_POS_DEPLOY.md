# Checklist pós-deploy
- [ ] `/health`, banco, config, `/health/web` e `/SystemHealth` respondem
- [ ] login, dashboard e diagnósticos abrem sem 404
- [ ] resposta pública e LGPD persistem; participação atualiza
- [ ] previews de relatório/certificado e validação pública abrem
- [ ] notificações, governança, integrações e assets carregam
- [ ] erros são sanitizados e exibem correlationId
- [ ] logs não contêm token, senha, e-mail puro ou payload sensível
- [ ] backup pós-deploy registrado; alertas e métricas acompanhados
