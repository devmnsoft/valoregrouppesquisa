# Design system premium Valora

A identidade usa navy profundo como superfície institucional, azul-petróleo para profundidade, aqua para foco/ação, branco e cinzas azulados para legibilidade. Dourado não é cor funcional. `valora-design-system.css` permanece a fonte central; `valora-auth.css` contém apenas composição específica da jornada de identidade.

Controles preservam alvo amplo, foco de três pixels, labels explícitos e mensagens com `role=alert`. Em até 800 px a narrativa é reduzida e o formulário passa a ser a prioridade. Movimento é desabilitado com `prefers-reduced-motion`.
