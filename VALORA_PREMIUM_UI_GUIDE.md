# Guia UI Premium Valora

A UI oficial usa ASP.NET Core MVC/Razor, Bootstrap, JavaScript puro e o design system `backend/Valora.Web/wwwroot/css/valora-design-system.css`.

## Tokens obrigatórios
Use `--valora-navy`, `--valora-aqua`, `--valora-bg`, `--valora-surface`, `--valora-text`, `--valora-muted`, `--valora-line`, `--valora-radius` e `--valora-shadow`.

## Componentes
Prefira classes com prefixo `.valora-`: shell, section, hero, card, button, badge, chip, kpi, table, form, alert, empty, skeleton, sidebar e topbar.

## Conteúdo público
Usar sempre Valora Insight™. Não usar Valora Pulse™ em texto público, `HOME`, JSON bruto, stack trace ou mensagem técnica.

## Responsividade
Toda grid deve colapsar para uma coluna abaixo de 900px. Botões principais ficam 100% no mobile quando agrupados.
